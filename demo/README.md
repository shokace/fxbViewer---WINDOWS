# Try the demo

From the repository root, run:

```sh
./dev.sh demo
```

The application opens a separate temporary library containing **24,576 synthetic
presets in 192 parameter banks**, plus **24 private-chunk banks**. Its settings are
separate from your regular library, and the temporary files are removed when the
app closes. These are generated test banks, not playable artist presets or
Sylenth exports. Demo generation refuses to overwrite existing files.

Use the four **Try** buttons:

1. **glass lead** — find names and related word matches, with exact names first.
2. **lead glass** — the same 3,072 results in a different relevance order.
3. **glass leed** — recover `Glass Lead` and related names despite the typo. The
   results explicitly say **Similar name**, with **no exact matches** in the count.
4. **hidden lead** — find 24 private-chunk banks. The selected result previews
   `Hidden Lead` as embedded text without claiming a decoded preset name.

Try **Names only** to exclude private-bank text, or uncheck **Find similar names**
to turn off spelling recovery. Try `etoile pad` for accent-insensitive search, and
`"glass lead"` to restrict word order. Refresh twice to see unchanged banks reused;
**File → Rebuild from disk** forces a full read.

The demo shows search timing and index read/reuse counts. Search timing is the
engine lookup time; the separate benchmark includes model filtering and sorting.

## Capture a tour

```sh
./dev.sh demo --demo-capture /tmp/fxbviewer-demo-tour
```

After indexing, the app performs the four searches above and saves actual window
captures plus `tour.json` with query counts, engine timings, and typo flags. It
then remains open on the spelling-recovery example for you to interact with.
No screenshot is mocked or generated by an image model. On Wayland, prefix the
command with `QT_QPA_PLATFORM=xcb` if external window inspection is needed.
